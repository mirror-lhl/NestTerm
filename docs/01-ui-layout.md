# NestTerm 界面布局与交互规格

> 文档版本：v0.1（2026-10-26） · 对应代码：0.1.0（A 期）
> 同组文档：[产品范围](00-product-scope.md) · [IPC 契约](02-ipc-contract.md) · [数据库设计](03-database-schema.md)

目标：把 FinalShell 的高频路径压缩成**一屏内可完成**的操作；键盘优先、终端为王、文件面板不做成独立页面。

---

## 1. 设计原则

1. **终端占最大面积**：任何面板展开都不能把终端挤到 < 480px 宽（低于则强制折叠右侧面板）。
2. **一屏完成高频动作**：连上 → 看日志 → 改权限 → 传文件，不跳页面、不弹新窗口（编辑器除外）。
3. **状态永远可见**：连接态、cwd 同步态、传输进度、采集异常，都在固定位置显示，不靠 toast 猜。
4. **键盘可达**：搜索、新建、关标签、切标签、刷新文件列表均有快捷键；鼠标操作有对应右键菜单。
5. **危险操作二次确认**：删除连接/目录、覆盖文件、绑定 0.0.0.0、关闭有活动传输的标签。

### 3.1 尺寸与可拖拽边界

| 区域 | 默认 | 最小 | 最大 | 拖拽 |
| --- | --- | --- | --- | --- |
| 工具栏 | 44px | 固定 | 固定 | 否 |
| 会话侧栏 | 300px | 240px | 400px | 是（分隔条 4px，双击复位） |
| 标签栏 | 36px | 固定 | 固定 | 否 |
| 终端区 | 自适应 | 480px | — | 与右侧面板联动 |
| 右侧 Dock | 400px | 340px | 560px | 是（分隔条 4px） |
| ├ SFTP 面板 | 自适应 | 220px | — | 与监控面板上下分栏 |
| └ 监控面板 | 240px | 180px | 360px | 是（折叠后仅标题栏 32px） |
| 状态栏 | 26px | 固定 | 固定 | 否 |

窗口最小 1024×640，默认 1280×820。布局尺寸持久化到 `settings`（见 [数据库设计](03-database-schema.md) §6 的 `settings` 表），键：`ui.sidebarWidth` / `ui.dockWidth` / `ui.monitorHeight` / `ui.monitorCollapsed`。

### 3.2 响应式行为

| 窗口宽度 | 行为 |
| --- | --- |
| ≥ 1440 | 三栏：侧栏 + 终端 + Dock（SFTP + 监控同时可见） |
| 1280–1439 | 监控自动折叠为标题栏，点击标题栏展开为**浮层**（覆盖 SFTP 下半部分，不挤压终端） |
| 1024–1279 | 侧栏可折叠（工具栏左侧按钮）；Dock 宽度收紧到 340；监控默认折叠 |
| < 1024 | 不允许（窗口最小宽度限制） |

**终端保护规则**：`终端可用宽度 = 窗口宽 - 侧栏宽 - Dock宽 - 分隔条`，若 < 480px，自动折叠监控；仍 < 480px 则自动收起 Dock（SFTP 变为底部抽屉，高度 40%）。

## 4. 区域规格

### 4.1 工具栏

| 控件 | 行为 | 快捷键 |
| --- | --- | --- |
| `+ 连接` | 打开「新建连接」对话框（默认聚焦主机输入） | `⌘/Ctrl + T` |
| `+ 分组` | 打开「新建分组」对话框，默认父级为当前选中分组 | `⌘/Ctrl + Shift + N` |
| `⇪ 导入` | 打开导入向导（FinalShell / 本应用 JSON） | — |
| `⇩ 导出` | 导出选中连接或全部；弹出选项（是否含凭据） | — |
| 搜索框 | 聚焦侧栏搜索，实时过滤 | `⌘/Ctrl + K` |
| `⚙` | 设置对话框（终端、外观、传输、监控、安全） | `⌘/Ctrl + ,` |

工具栏不显示连接按钮 —— 连接动作在会话树双击 / 标签页 + 号 / 快速连接。

### 4.2 会话侧栏（树）

**节点类型**：分组（可嵌套，建议 ≤ 3 层）、连接、虚拟节点「未分组」。

**分组行**：

- 折叠箭头 + 名称 + 连接计数（`生产环境 (2)`，仅显示直接子项数）。
- 双击重命名（F2 同效）；右键菜单：新建子分组 / 重命名 / 删除 / 导出该分组。
- 拖拽：分组可拖入其他分组（禁止拖入自身子树）；拖拽时显示插入线（同级排序）或高亮（成为子项）。

**连接行**：

- 状态点（见 §6.1）+ 名称 + 右侧悬浮显示 `host:port`（截断，tooltip 全量）。
- 双击：打开会话标签（已打开则切换过去，不重复开）。
- 单击：选中并在状态栏右侧显示主机信息；不连接。
- 右键菜单：打开 / 在新标签打开 / 快速连接（不保存）/ 编辑 / 复制 / 删除 / 在此分组新建。
- 拖拽：可换分组、可排序；跨分组拖拽后立即写库（乐观更新 + 失败回滚）。
- 多选：`⌘/Ctrl` 点选、`Shift` 连选；支持批量删除/导出/移动。

**搜索**：

- 输入即过滤（150ms 防抖），匹配名称、主机、用户名、标签、备注。
- 有匹配时自动展开祖先分组；无匹配显示空态「没有匹配的连接」+ 清除按钮。
- 键盘：`↑/↓` 选择，`Enter` 打开，`Esc` 清空并退出搜索。

**空态**：无任何连接时，树区显示引导卡片「新建第一个连接」，含「导入 FinalShell 配置」次按钮。

### 4.3 标签栏

- 每个标签对应一个 Session；标签内容 = 终端 + 右侧 Dock + 监控。
- 标签结构：状态点 + 名称（Profile 名；临时连接用 `user@host`）+ 关闭按钮。
- 状态点：连接中 = 旋转环；已连接 = 绿点；重连中 = 琥珀色呼吸；错误 = 红点（tooltip 显示错误码）；已断开 = 灰点。
- 溢出：横向滚动 + 右侧下拉列出全部标签；最多同时 20 个标签（超出提示先关闭）。
- 拖拽排序；中键关闭；关闭已连接标签需确认（设置项 `confirmOnCloseTab`，默认开）。
- 新标签按钮 `+`：打开快速连接对话框（临时会话，不保存）。
- 空标签区显示 Welcome：最近连接（P1）、快捷键提示、导入入口。

### 4.4 终端面板

- xterm.js 6，`FitAddon`；`scrollback` 10000（可配）；`macOptionIsMeta: true`；`cursorBlink` 可配。
- 顶部无额外工具条（节省高度）；操作全部在右键菜单与快捷键。
- 右键菜单：复制 / 粘贴 / 全选 / 清屏 / 查找（P1）/ 保存日志（P1）/ 字体放大 / 字体缩小 / 重置字号。
- 粘贴：> 64KB 时先提示「粘贴 N KB 文本？」（防误粘贴卡死）；单次上限 4MB。
- 复制：有选中内容时 `⌘/Ctrl+C` 复制（不发送 SIGINT）；无选中时发送 `\x03`。`⌘/Ctrl+Shift+C/V` 强制走复制/粘贴。
- 查找：P1 用 `@xterm/addon-search`；本期不显示入口，避免假功能。
- resize：`ResizeObserver` → `FitAddon.fit()` → 80ms 防抖 → `ssh_resize`。
- 断线恢复：终端保留内容，插入分隔线 `── 连接断开 20:41:03 · 正在重连（1/5）──`；重连成功插入 `── 已重新连接 20:41:09 · 新会话 ──`。

### 4.5 SFTP 面板

> B2a 已落地：路径栏、列表、在线编辑、权限、重命名、删除、跟随终端 cwd。
> B2b-1 已落地：文件上传/下载、拖拽上传、传输托盘、进度/取消、冲突策略。
> B2b-2a 已落地：目录递归上传/下载（含空目录/隐藏文件）。
> 下载目录选择器、拖拽下载属 B2b-2b。

```
┌───────────────────────────────────────────────────────────────┐
│ [⟲] [⌂] [↑]  / var log nginx            [跟随终端 ●] [隐藏文件]│ 路径栏 36
├───────────────────────────────────────────────────────────────┤
│ [⬆ 上传] [⬇ 下载] [＋目录] [✎ 重命名] [🗑 删除] [🔒 权限] [⟳]  │ 工具条 34
├───────────────────────────────────────────────────────────────┤
│ 名称                    │ 大小    │ 修改时间        │ 权限       │ 表头 28
│ 📁 conf                 │ 4.0 KB  │ 2026-10-20 10:12│ drwxr-xr-x │
│ 📄 access.log           │ 12.4 MB │ 2026-10-26 20:30│ -rw-r--r-- │
│ 🔗 current -> /etc/ngx  │ —       │ 2026-10-01 09:00│ lrwxrwxrwx │
├───────────────────────────────────────────────────────────────┤
│ 传输 (2)  ▲                                                    │ 传输托盘 32/200
│  access.log  68%  ████████░░  8.4MB/s  ETA 2s            [✕]   │
└───────────────────────────────────────────────────────────────┘
```

**路径栏**：

- 面包屑：`/` 根 + 各级可点击；超过 4 级时中间折叠为 `…` 下拉。
- 点击路径文本切换为输入框（`/` 自动补全为根）；`Enter` 跳转，`Esc` 取消。
- `跟随终端`：开启时终端 cwd 变化驱动面板；关闭时面板独立导航（状态栏仍显示当前目录）。默认开启。
- `隐藏文件`：默认关闭；状态持久化。
- 错误：路径不存在/无权限时，保留上一级列表并在路径栏下方显示红色提示条，3s 后淡出（不遮挡列表）。

**表格**：

- 列：名称、大小（目录显示 `—`，文件人性化单位）、修改时间、权限（`rwxr-xr-x` + 悬浮显示八进制/uid/gid）。
- 排序：点击表头切换 名称/大小/时间；目录始终排前。
- 单目录超过 5000 项时截断，表格底部提示「仅显示前 5000 项，建议在终端用 `find`/`ls` 精确查找」。
- 选中：单击、`⌘/Ctrl` 多选、`Shift` 连选、`⌘/Ctrl+A` 全选。
- 双击：目录进入；文本文件打开内置编辑器；二进制文件提示「不支持在线编辑，是否下载？」。
- 右键菜单：打开 / 编辑 / 下载… / 重命名 / 删除 / 权限 / 复制路径 / 在终端中打开（生成 `cd`）。
- 拖拽：从 Finder 拖入 → 上传到当前目录；从表格拖出 → P0 只支持「下载到…」（macOS 拖出到 Finder 待评估，见 §10 风险）。
- 排序/过滤状态不持久化（每次进入目录重置为名称升序）。

**底部传输托盘**：

- 折叠高度 32px，显示「传输 (N)」+ 总体进度；展开高度 200px，列出每个任务（方向、文件名、进度、速度、ETA、取消）。
- 完成/失败任务保留 30s 后自动移除；失败项提供「重试」。
- 关闭标签时若有进行中传输：确认「有 N 个传输未完成，关闭将取消」。

### 4.6 监控面板（侧边实时）

- 折叠态：32px 标题栏，显示摘要 `CPU 12% · 内存 38% · 负载 0.42`，右侧 `⏸/▶` 与展开箭头。
- 展开态卡片：
  1. **CPU**：当前使用率大数字 + 60 点 sparkline（2s 采样 = 2 分钟窗口）。
  2. **内存**：已用/总量 + 百分比进度条；swap 一行小字。
  3. **负载**：1/5/15 三个数字；与核数比较的颜色阈值（>核数 黄，>2×核数 红）。
  4. **磁盘**：按挂载点列出前 4 个（按使用率倒序），进度条 + `已用/总量`；更多挂载点折叠为「+N」。
  5. **网络**：rx/tx 实时速率 + 双色 sparkline；累计流量小字。
  6. **系统**：运行时长、内核版本（连接时采集一次，不随采样刷新）。
- 采样间隔默认 2s，可在设置中 1–10s；标签不可见（切走）时暂停，切回立即刷新。
- 采集失败：卡片区顶部黄条「采集失败：命令超时（重试中 3/5）」，保留上一次数据并标注「数据为 20:41:02 的采样」。
- 非 Linux 服务器：显示「当前系统暂不支持完整监控（仅 CPU/内存）」并降级展示可用字段。

### 4.7 状态栏

从左到右：

1. 连接状态点 + 文案（未连接 / 连接中 / 已连接 / 重连中 / 已断开 / 错误）。
2. 会话时长（`00:12:33`，连接成功后计时）。
3. 认证方式（密码 / 私钥 / agent）。
4. cwd 同步状态：`跟随终端 /var/log` 或 `已暂停跟随`。
5. 传输数（`2 个传输`，点击展开传输托盘）。
6. 延迟（`12ms`，来自 keepalive RTT 或每 10s 一次 `ssh_ping`；P1 若成本高可移除）。

### 4.8 对话框清单

| 对话框 | 触发 | 关键字段 / 校验 |
| --- | --- | --- |
| 新建/编辑连接 | `+ 连接`、右键编辑 | 名称、分组、主机、端口、用户、认证方式（密码/私钥/agent）、私钥路径+口令、TERM、keepalive、备注；「测试连接」按钮（不保存，结果就地显示） |
| 新建/重命名分组 | `+ 分组`、F2 | 名称（同级去重）、父级（树选择） |
| 快速连接 | `⌘T`、标签 `+` | 主机、端口、用户、认证；勾选「保存到会话列表」才写库 |
| 导入向导 | 工具栏 | 来源（FinalShell 目录/JSON、NestTerm JSON）、预览统计、冲突策略（跳过/覆盖/重命名）、目标分组 |
| 导出 | 工具栏 | 范围（选中/全部）、格式（JSON）、是否含凭据（需口令） |
| 修改权限 | SFTP 工具条/右键 | 9 个 rwx 复选框 + 八进制输入（双向同步）+ 预设 644/755/600 |
| 在线编辑 | 双击文本文件 | 内容、只读态（超限/二进制）、行数/大小、保存/另存为；冲突提示 |
| 端口转发 | 转发页/会话菜单 | 类型（-L/-R/-D）、名称、绑定地址/端口、目标地址/端口、自动启动；绑定 0.0.0.0 红字确认 |
| 设置 | `⚙` | 外观、终端、传输、监控、安全、关于 |
| 确认框 | 删除/覆盖/关闭 | 标题、影响描述、危险按钮红色、默认焦点在「取消」 |

## 5. 关键交互时序

### 5.1 终端 cd → SFTP 跟随

```
用户: cd /var/log/nginx ⏎
  │
  ├─ xterm onData ──► ssh_write(keys) ──► 远端 shell
  │
  ├─ 终端输出 ──► 解析 shell 提示符（~/path） ──► SFTP 列表刷新（丢弃过期响应）
  │                        │
  │                        └─否──► 输入启发式（cd/pushd 命令 + 150ms 后 sftp_realpath 校验）
  │                                  └─仍失败──► cwd 未知，路径栏保持灰色「未知目录」
  │
  └─ 用户手动关闭「跟随终端」──► 后续 ssh:cwd 只更新状态栏，不刷新列表
```

- 解析在 Rust 侧完成（输出字节同时转发给 xterm，**不消费、不修改**），避免前端忙时丢状态。
- 同一路径重复事件去重；`/proc` 不可见时不阻塞终端。
- 反向同步：SFTP 路径栏「在终端中打开」按钮，向终端写入 `cd '<path>'` + `⏎`（路径单引号转义），**绝不自动执行**。

### 5.2 拖拽上传

```
Finder 拖入 SFTP ──► Tauri 拖放事件（本地绝对路径列表）
   │
   ├─ 冲突检测：远端同名？──是──► 冲突策略对话框（覆盖/跳过/重命名/全部应用）
   │
   ├─ sftp_upload({sessionId, localPaths, remoteDir, conflictPolicy})
   │      └─► 返回 transferIds
   │
   └─ transfer:progress（≥1/s）──► 托盘进度条
          └─► transfer:done / transfer:error ──► 托盘状态 + 列表刷新
```

### 5.3 在线编辑保存（防覆盖）

```
双击 access.log ──► sftp_read_file(path) ──► { content, mtime, size, mode, truncated }
   │
   ├─ 打开编辑器（内容 > 2MB / 含 NUL → 只读 + 提示）
   │
   └─ ⌘S ──► 保存前 stat 远端
             ├─ mtime/size 与读取时一致 ──► 写临时文件 .nestterm.<rand>.tmp ──► rename 覆盖
             └─ 不一致 ──► 冲突对话框：保留我的 / 重新加载远端 / 另存为
```

## 6. 状态与反馈

### 6.1 会话状态矩阵

| 状态 | 色值 | 树/标签指示 | 允许操作 |
| --- | --- | --- | --- |
| `idle` | 灰 | 空心点 | 连接、编辑、删除 |
| `connecting` | 蓝 | 旋转环 | 取消连接（关闭标签） |
| `connected` | 绿 | 实心点 | 全部 |
| `reconnecting` | 琥珀 | 呼吸点 | 取消重连、断开 |
| `disconnected` | 灰 | 空心点 | 重连、关闭 |
| `error` | 红 | 红点 + tooltip 错误码 | 重连、编辑、查看详情 |

> `idle` 是前端派生状态（未连接且非错误），不来自后端事件；后端只发 `connecting/connected/reconnecting/disconnected/error`。

### 6.2 空态 / 加载 / 错误

| 场景 | 呈现 |
| --- | --- |
| 无连接 | 引导卡片 + 「新建连接」「导入配置」 |
| 无搜索结果 | 「没有匹配的连接」+ 清除搜索 |
| SFTP 加载中 | 表格骨架 3 行（不闪白、不阻塞终端） |
| SFTP 空目录 | 居中「空目录」+ 上传按钮 |
| SFTP 无权限 | 路径栏红色提示 + 返回上级按钮 |
| 监控无数据 | 「等待首次采样…」 |
| 终端未连接 | 终端区居中提示「点击左侧连接开始」+ 快捷键提示（不遮挡已断开的历史输出） |

### 6.3 通知策略

- **toast**：仅用于一次性结果（导入完成、导出完成、复制成功、转发已启动），3s 自动消失。
- **常驻提示条**：用于需要用户处理的状态（指纹变更、采集失败、传输失败），必须手动关闭。
- **禁止**：用 toast 报告连接失败等关键错误（用户可能错过）；错误必须出现在对话框或状态栏。

## 8. 主题与可访问性

- 深色主题为默认且 P0 唯一完整主题；浅色主题 P1（需同时校准终端 16 色）。
- 所有可点击元素有 `:focus-visible` 描边（`--primary` 2px，offset 2px），不依赖 hover。
- 图标按钮必须有 `aria-label` 与 tooltip；状态点除颜色外必须有形状/文字差异（色盲可辨）。
- 传输完成、会话断开使用 `aria-live="polite"` 区域播报。
- 窗口缩放 125% 下布局不重叠（Element Plus 默认字号可被浏览器缩放继承）。
- 尊重 `prefers-reduced-motion`：关闭呼吸/旋转动画（状态改为静态图标 + 文案）。
